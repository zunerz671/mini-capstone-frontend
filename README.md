# Volleyball Manager Frontend

A React frontend for managing volleyball teams and games with Neo-Brutalism design.

## Features

- User authentication (login/signup)
- Team management (CRUD operations)
- Game tracking and scoring
- Dashboard with statistics
- Role-based access control (admin/user)

## Setup

1. Install dependencies:
```bash
npm install
```

2. Create a `.env` file based on `.env.example` and configure your Rails backend URL

3. Start the development server:
```bash
npm run dev
```
